How to import your Google Maps places
  1. Open takeout.google.com. Tap Deselect all. Tick Saved and Maps (your places). Create the export.
  2. On the Mac, unzip it to Downloads/Takeout and run tools/takeout_to_sheet.py. It makes Travel Plan import.csv.
  3. Open it in Excel. Fix City and Category. Rows marked CHECK or NOT FOUND need a look. Set Include to no to skip a row.
  4. Excel: File › Save As, format CSV UTF-8 (Comma delimited). Plain “CSV” breaks Hebrew.
  5. Tap Import from Maps and choose that CSV.
Places you already saved are skipped, so you can import again after more fixes.
